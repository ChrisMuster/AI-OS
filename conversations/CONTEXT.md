# Conversations

**Last modified:** 2026-06-03

## Purpose
A personal archive of notable conversations with Biblio, saved by choice when a discussion is worth keeping. Each file is a summarised record of ideas explored, decisions made, and threads left open.

## Contents
Saved conversation files, named `YYYY-MM-DD-topic-slug.md`. Each file follows the standard conversation format: date, topic, summary, and open threads. Individual files are not listed here as they are personal content.

## Inputs
User decision to save a conversation. User provides or approves a title before the file is written.

## Outputs
One markdown file per saved conversation, written to this directory.

## Steps
N/A — not a workflow directory. Saving is triggered on demand during any session:
1. User requests save.
2. Biblio proposes a title; user confirms or changes it.
3. Biblio summarises the conversation (or saves verbatim if short).
4. File is written to `conversations/` using the naming convention `YYYY-MM-DD-topic-slug.md`.
5. Append `conversations/LOG.md` with a completion entry.

## Dependencies
- [[SOUL.md]] — Biblio's identity and behavioural rules govern how summaries are written.
- [[journal]] — Parallel personal archive; journals capture daily life, conversations capture explored ideas.
- [[wikis]] — Parallel structured knowledge base; conversations are raw source material that may eventually feed wiki pages.

## Known Issues
- Summaries are generated by the AI and reflect the model's judgement of what mattered. Review before relying on them as a definitive record.
